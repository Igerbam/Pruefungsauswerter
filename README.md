# Pruefungsauswerter
Tool für Lehrer zum Berechnen von Noten für geschriebene Prüfungen.

Dieses Tool ist im Rahmen einer Facharbeit in der 11. Klasse des Gymnasiums entstanden.\
Diese Vergleicht das Speichern von Daten in Dateien und in relationalen Datenbanken.

**Keine einzige Zeile Code** in diesem Projekt wurde mithilfe von AI erstellt.
